AgentIsland

AgentIsland 是一款 macOS 菜单栏应用：把你的编码 Agent 挂在 MacBook 刘海上 —— Claude Code、Oh My Pi、Pi 与 OpenCode 的实时会话状态、对话历史与工具审批。
A macOS menu bar app that puts your coding agents on the MacBook notch — live session state, chat history and tool approvals for Claude Code, Oh My Pi, Pi and OpenCode.
